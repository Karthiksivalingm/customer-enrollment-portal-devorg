# 03-Requirements

One dated record per requirement, change request, enhancement or defect: `YYYY-MM-DD-REQ-NNN-<slug>.md`.
Create with `node scripts/new-doc.js REQ "<title>"` (template: [config/templates/REQ.md](../config/templates/REQ.md)).

Each record holds the original request, business objective, acceptance criteria, scope, affected components, dependencies,
open questions, approval status and implementation status. Never invent ticket IDs, requesters or approvals.
