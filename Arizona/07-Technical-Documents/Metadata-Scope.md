# Metadata Scope

The baseline in `manifest/package.xml` lists **explicit component names** (no wildcards) of the in-scope types. It is built by
`node scripts/list-org-metadata.js` + `node scripts/build-manifest.js` from the rules in
[`config/arizona-project.json`](../config/arizona-project.json), and split into six retrieval batches in `manifest/batches/`.

## In scope

| Area | Rule |
|---|---|
| Code | Every unmanaged ApexClass, ApexTrigger, ApexPage, ApexComponent, LightningComponentBundle, AuraDefinitionBundle, StaticResource |
| Data model | Unmanaged custom objects ending `__c`, `__mdt`, `__e`, `__kav`; standard objects that carry unmanaged custom fields (Account, Contact, Lead, Case, Opportunity, Activity); the unmanaged fields on the managed `pandadoc__PandaDocDocument__c`; GlobalValueSet; CustomMetadata records |
| UI | Layouts and object QuickActions of in-scope objects, global QuickActions, FlexiPages, CustomTabs, CustomApplications |
| Automation | Flows, Workflow, Assignment / Auto-Response / Escalation rules, Duplicate and Matching rules, PlatformEventChannel, Queues |
| Security and integration | PermissionSets, CustomPermissions, SharingRules of in-scope objects, NamedCredential, ExternalCredential, RemoteSiteSettings, CspTrustedSites, ConnectedApp |
| Reports and email | ReportTypes; reports and dashboards in business folders; email templates |
| Experience Cloud | Network, CustomSite, ExperienceBundle |

## Out of scope

| Excluded | Reason |
|---|---|
| Managed-package components (23 installed packages, e.g. `pandadoc`, `pi`, `rcsfl`, `tdc_tsw`, `echosign_dev1`, `Calendly`, `docb`) | Owned by the vendor; excluded by namespace in `.forceignore` |
| Data Cloud / Data 360 objects (`__dll`, `__dlm`, `__hd`, `ssot__*`, about 100 objects) | System-generated by Data Cloud data streams and models |
| Report/dashboard folders `EinsteinBotReports*`, `EBotR_*`, `sfdw_*` | Platform-generated analytics packs |
| Profiles (34) | Same baseline decision as the other projects in this repository; access is documented through permission sets |
| AuthProviders (12) | Platform-generated for Data Cloud, advertising and web connectors |
| CustomLabels (2: `PandaDoc_API_Key`, `PandaDoc_Webhook_Key`) | Named as credentials; read by `PandaDocApi` and `PandaDocWebhook`. Not retrieved, so no secret values reach the repository. |
| Record data | Retrieval never touches records |
