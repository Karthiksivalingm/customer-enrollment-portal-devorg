# Goodr Project — Document Index

Every project document, by folder and serial number. **Last updated:** 2026-10-14 (generated by `scripts/doc-builders/build_document_index.ps1`).

## Naming convention
`<PREFIX>-<3-digit serial>_<Short-Title-With-Hyphens>.md`, for example `REQ-012_Cluster-Not-Updating-For-Sector-Only-Change.md`.

| Folder | Prefix | What goes in it | Next free number |
|---|---|---|---|
| `01-Instructions` | — | How work is done. `AI-Workflow.md` and `Coding-Standards.md` are shared across projects and **read-only**; `Project-Rules.md` holds the Goodr rules | — |
| `02-Knowledge-Base` | `KB-` | Background: overview, process, integrations, environment | KB-005 |
| `03-Requirements` | `REQ-` | One per requirement: need, scope, acceptance criteria, open questions | REQ-034 |
| `04-Change-Records` | `CR-` | One per change made to an org or the repo: what, when, deploy ID, verification, rollback | CR-025 |
| `05-Conflicts` | `CON-` | Problems faced, clashes, open risks | CON-034 |
| `06-Deployment` | `DEP-` | Production deployment documents, packages, checklists, QA | DEP-003 |
| `07-Technical` | `TECH-` | Technical design, component inventories, secure configuration | TECH-008 |

**Rules:**
- Numbers are never reused. A cancelled item keeps its number and is marked as such. REQ-027 to REQ-029 are not used.
- An existing document is **updated** when its topic changes; a new topic gets a new number.
- Every document links to its related REQ, CR, CON, DEP and TECH documents.
- Every change to an org (a deploy, a Setup change or a data load) gets a CR the same day.
