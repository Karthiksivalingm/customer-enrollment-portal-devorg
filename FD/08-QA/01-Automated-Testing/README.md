# 01-Automated-Testing

Automated test reports (ATR) for FD requirements. See [QA-Process.md, section 5](../../01-Instructions/QA-Process.md#5-automated-test-report-atr).

- **File name:** `ATR-###_<Requirement>.md`, using the next free number from `DOCUMENT-INDEX.md`
- **Optional:** a test class written only for the run can be kept beside it as `ATR-###_<ClassName>.cls`
- **Contents, in order:** header, scope, how the tests were run, scenario results, defects found, evidence, test data and cleanup
