# 02-Manual-Testing

Manual test cases (MTC) for the QA tester, for FD requirements. See [QA-Process.md, section 6](../../01-Instructions/QA-Process.md#6-manual-test-cases-mtc).

- **File name:** `MTC-###_<Requirement>.md`, using the next free number from `DOCUMENT-INDEX.md`
- **Screenshots:** put them in `MTC-###_screenshots/`, named by test ID, for example `TC-004-02_owner_not_ooo.png`
- **Expected result:** always the outcome the automated run (ATR) actually produced
- **Actual result and Status:** left blank for the tester
