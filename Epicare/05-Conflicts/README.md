# 05 — Conflicts

One dated record per meaningful error or conflict: `YYYY-MM-DD-CF-NNN-short-description.md` (`python scripts/new_doc.py CF "<title>"`).
Covers metadata conflicts, conflicting requirements, dependency problems, failed retrievals, test or validation failures, Git merge
conflicts, and permission or authentication errors. **Update the existing record** while a problem stays unresolved; use `--key` to avoid duplicates.
