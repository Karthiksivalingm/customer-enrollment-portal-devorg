# CON-001 — Metadata API failed to return sample reports, dashboard and a connected app

| Field | Value |
|---|---|
| **ID** | CON-001 (formerly CF-001) |
| **Found** | 2026-10-15, baseline retrieval from UTDEV (`00DWB000008ALkv2AG`) with `scripts/retrieve.py` |
| **Related requirement / change** | Epicare project setup (baseline retrieval). No REQ |
| **Status** | Open. Accepted as an exception; no impact on Epicare source |

## Error message and evidence
Batches `ui` and `routing` succeeded overall. For individual components the Metadata API returned:
```
Metadata API received improper input. Please ensure file name and capitalization is correct.
Load of metadata from db failed for metadata of type:Report and file name:CRM_180925_Sample_Sales_Reports/CRM_180925_...
Load of metadata from db failed for metadata of type:Dashboard and file name:CRM_180925_HVS_Sample_Dashboard_Folder/CRM_180925_HVS_Sample_Dashboard
Load of metadata from db failed for metadata of type:ConnectedApp and file name:CPQIntegrationUserApp
```
Full list: [Retrieval-Report.md](../07-Technical/Retrieval/Retrieval-Report.md#components-not-returned).

## Affected components
- 22 reports in folders `CRM_180925_Sample_Sales_Reports` and `CRM_180925_Sample_Sales_Dashboards_Reports`.
- Dashboard `CRM_180925_HVS_Sample_Dashboard_Folder/CRM_180925_HVS_Sample_Dashboard`.
- Connected app `CPQIntegrationUserApp`.

## Investigation performed
| Date | Step | Finding |
|---|---|---|
| 2026-10-15 | Read the retrieval results | Every other component in the same batches was returned. The failures are confined to these names |
| 2026-10-15 | Checked folder names | The `CRM_180925_*` folders hold sample Sales Engagement / High Velocity Sales content. INFERENCE: generated by Salesforce, not by Epicare |

## Potential causes (suspected, not confirmed)
- The sample reports and dashboard reference report types or features not available to the retrieving user or edition.
- `CPQIntegrationUserApp` is a Salesforce-managed connected app that cannot be read through the Metadata API.

## Confirmed root cause
Not confirmed.

## Resolution
Accepted as exceptions. `scripts/check_retrieval.py` lists them as explained gaps. **882 of 909** named components were returned,
and none of the remaining gaps is unexplained.

## Remaining risks and follow-up actions
- If any of these components becomes relevant to a requirement, open it in Setup and decide whether it should be rebuilt.
