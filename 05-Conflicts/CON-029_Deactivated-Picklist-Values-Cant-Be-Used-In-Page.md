# CON-029 — Deactivated picklist values can't be used in page filters, and record

| | |
|---|---|
| **ID** | CON-029 |
| **Status** | ⚠ Open risk |
| **Found** | 2026-10-12 |
| **Where** | Pages, record types |

## Risk
Deactivated picklist values can't be used in page filters, and record types must list the new values

## Mitigation
Add the values to record types before data loads
