# Requirements

Use this section to track the tasks and requirements that come in each day.

- **[Requirements-Log.md](Requirements-Log.md):** one row per requirement. It's the daily view.
- **[Requirement-Template.md](Requirement-Template.md):** copy it into `Requirements/REQ-xxxx-<short-name>.md` for any requirement that needs analysis, design or testing notes.

**Statuses:** New → In Analysis → In Progress → In Review/QA → Ready to Deploy → Deployed → Closed (or On Hold / Rejected)

**Priority:** P1 means production is impacted, P2 is needed this sprint, P3 is planned, and P4 is nice to have.
