# 02 — Manual Testing

One Word document per requirement: `MTC-###_<Requirement>.docx`, written for the manual QA tester.

## Test case columns
| Column | Content |
|---|---|
| Test ID | Same ID as the automated report, for example TC-014-03 |
| Scenario | What is being tested |
| Preconditions | Login, profile, record and data needed before starting |
| Front-end steps | Numbered clicks and entries, with screenshots |
| Backend check | Field, record or query to confirm after the steps |
| Test data | Values to enter |
| Expected result | The verified outcome from the automated run |
| Actual result | Filled in by the QA tester |
| Status | Pass / Fail, filled in by the QA tester |

The document ends with a summary table of all scenarios and a sign-off section.
